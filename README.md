# vapour-protocol

Rust implementation of the Steam client protocol for building native Steam applications.

## Scope

`vapour-protocol` is intended to stand on its own as a reusable library, separate from the Vapour TUI application. The long-term target is client-side Steam use cases such as authentication, friends, chat, library access, and other real-time protocol features.

## Status

Early scaffold. The crate is separated now so it can evolve and be released independently from the main Vapour application.
